POLÍTICA DE PRIVACIDAD

Queremos que sepas qué ocurre con tus datos cuando utilizas AnxanWoman.

Datos personales y cuentas de usuario

AnxanWoman permite acceder a determinadas funcionalidades mediante cuentas de usuario, utilizando Firebase Authentication, un servicio proporcionado por Google.

Dependiendo del método de acceso utilizado, pueden tratarse datos como el identificador de usuario, la dirección de correo electrónico y la información necesaria para autenticar y mantener la sesión.

AnxanWoman utiliza Firebase Cloud Firestore para gestionar determinadas funcionalidades, como las participaciones en concursos, el control de votaciones y las recompensas asociadas a las cuentas.

Estos datos se utilizan para permitir el funcionamiento de la web, gestionar la participación de los usuarios y prevenir participaciones duplicadas o usos indebidos.

Puedes consultar información sobre el tratamiento de datos de Google en su política de privacidad .

Rayitos y progreso

AnxanWoman dispone de un sistema de puntos virtuales denominado Rayitos, que permite participar en determinadas actividades de la web.

Algunas funciones, como el quiz y la ruleta, pueden almacenar temporalmente información sobre puntos, partidas y progreso mediante el almacenamiento local del navegador (localStorage).

Además, determinadas recompensas diarias se registran en Firebase Cloud Firestore, asociadas al identificador de la cuenta del usuario.

Esta información se utiliza para gestionar las actividades, recordar el progreso y controlar determinadas recompensas.

Los datos guardados en el navegador pueden desaparecer si el usuario borra el almacenamiento local o cambia de dispositivo.

Los Rayitos son puntos virtuales de uso interno en AnxanWoman. No representan dinero real ni tienen valor monetario.

Servicios externos

AnxanWoman utiliza servicios de terceros para ofrecer sus funcionalidades y conocer el uso general de la página web.

Google Firebase

Utilizamos Firebase Authentication para gestionar el acceso de usuarios y Firebase Cloud Firestore para almacenar determinada información relacionada con las cuentas, votaciones y recompensas.

Cloudflare Web Analytics

Utilizamos Cloudflare Web Analytics para obtener estadísticas agregadas sobre las visitas a la web y sus diferentes páginas. Este servicio no utiliza cookies para realizar el seguimiento de las visitas.

Google AdSense

AnxanWoman ha solicitado la incorporación de Google AdSense como servicio publicitario. Actualmente, la activación de anuncios está pendiente de aprobación.

Si se activa este servicio, Google y sus proveedores publicitarios podrán utilizar cookies u otras tecnologías, según las preferencias de consentimiento del usuario y la normativa aplicable.

Redes sociales y plataformas externas

La web incluye enlaces a plataformas como YouTube, Twitch, TikTok y Discord. Al acceder a ellas se aplicarán sus propias políticas de privacidad.

Puedes consultar más información en las políticas de privacidad de Google y Cloudflare.

Si estas funciones implican nuevos tratamientos de datos personales, esta política será actualizada antes o al incorporarlos, según corresponda.
